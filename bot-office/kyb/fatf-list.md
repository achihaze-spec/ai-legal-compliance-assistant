## How to update this file
1. Open the FATF "black and grey lists" page and the latest "Jurisdictions under Increased Monitoring" and "High-Risk Jurisdictions subject to a Call for Action" publications.
2. Replace both lists, record additions and removals, and update the three dates at the top.
3. Repackage the plugin (or edit the file in place) so every skill picks up the change.
