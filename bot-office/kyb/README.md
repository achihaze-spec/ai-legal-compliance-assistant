# kyb/ (screening toolkit)

Copied from the evercrest-kyb plugin's kyb-toolkit (author: Hazel Orila) so the Bot Office can run
the same maths: `kyb_common.py`, `name_match.py` (fuzzy match + 2 strong identifiers), `live_screen.py`
(OFAC / UN / EU / UK official lists, version log), `bo_calc.py` (UBO through every layer, OFAC 50% Rule),
`mrz_check.py` (ICAO 9303 check digits). `fatf-list.md` and `search-strings.md` are the reference lists.
When the plugin is updated, copy the changed files here too.
